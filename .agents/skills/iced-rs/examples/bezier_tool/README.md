# Bézier tool

Draw Bézier curves on an interactive Canvas.

![Drawing Bézier curves with Canvas](https://iced.rs/examples/bezier_tool.gif)

Read the [example source](src/main.rs).

## Run

Run from the root of the [Iced 0.14.0 workspace](../README.md#install).

```sh
cargo run --package bezier_tool
```
