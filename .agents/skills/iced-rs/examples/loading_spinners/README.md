# Loading spinners

Show animated circular and linear spinners for work without a known completion percentage.

Read the [circular](src/circular.rs) and [linear](src/linear.rs) widgets and their shared [easing functions](src/easing.rs).

Read the [example source](src/main.rs).

## Run

Run from the root of the [Iced 0.14.0 workspace](../README.md#install).

```sh
cargo run --package loading_spinners
```
