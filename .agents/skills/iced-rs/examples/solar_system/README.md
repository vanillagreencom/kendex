## Solar system

An animated solar system drawn using the `Canvas` widget and showcasing how to compose different transforms.

The __[`main`]__ file contains all the code of the example.

<div align="center">
  <img src="https://iced.rs/examples/solar_system.gif">
</div>

These sources are a read-only copy. To run it, clone the upstream workspace at the release (`git clone --branch 0.14.0 https://github.com/iced-rs/iced`) and, from its root:
```
cargo run --package solar_system
```
