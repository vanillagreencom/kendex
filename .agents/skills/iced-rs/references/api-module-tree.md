# Iced 0.14 API lookup

Read when looking up a public import, signature, or feature gate for the bundled Iced 0.14.0 examples. Start with the [versioned API documentation](https://docs.rs/iced/0.14.0/iced/) or the [crate exports at the skill’s pinned commit](https://github.com/iced-rs/iced/blob/3997291f318a8bc06fa522f5579836fb3feb94df/src/lib.rs). The [crate manifest](https://github.com/iced-rs/iced/blob/3997291f318a8bc06fa522f5579836fb3feb94df/Cargo.toml) declares feature flags.

Enable `advanced` for `iced::advanced`, `canvas` for Canvas, and `wgpu-bare` or `wgpu` for Shader. The `wgpu` feature also enables the default GPU backends. Enable `sysinfo` to call `iced::system::information()`.
