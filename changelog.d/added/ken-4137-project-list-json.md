- `kendex project list --json` prints the projects list as one JSON array, each entry giving the registered folder exactly, its state (`ok`, `folder-not-found`, `not-a-folder` or `unreadable`) and, where the folder's own git repository is checked out there as a linked worktree, the main checkout. A linked worktree that only encloses the folder's repository, such as one holding a submodule, is not reported. A program can now tell a folder whose name holds a newline, or ends like a worktree note, from the folder the plain rows would show it as. Where git cannot say whether a folder is a worktree, the command fails and names the folder. The plain rows are unchanged.
