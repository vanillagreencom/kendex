- `kendex project list --json` prints the projects list as one JSON array, each entry giving the registered folder exactly, its state (`ok`, `folder-not-found`, `not-a-folder` or `unreadable`) and, for a folder in a linked git worktree, the main checkout. A program can now tell a folder whose name holds a newline, or ends like a worktree note, from the folder the plain rows would show it as. Where git cannot say whether a folder is a worktree, the command fails and names the folder. The plain rows are unchanged.
