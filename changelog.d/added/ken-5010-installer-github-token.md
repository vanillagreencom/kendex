- `install.sh` takes a GitHub token in `KENDEX_GITHUB_TOKEN` and then looks up and downloads the release through `api.github.com` as that token's user, so an install or update keeps working while GitHub refuses anonymous downloads. The token goes to `api.github.com` alone, never into curl's arguments or the installer's output; a refused token stops the install with `github-token-rejected` instead of falling back to anonymous requests. Without the variable, or with it empty, the installer sends the same anonymous requests as before, and it does not read `GH_TOKEN` or `GITHUB_TOKEN`.
