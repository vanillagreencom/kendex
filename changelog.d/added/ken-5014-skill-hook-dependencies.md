- A skill's `SKILL.md` can name hooks from its own catalog under `dependencies.hooks`, and installing the skill installs each hook, with its settings entry, on the skill's tools that the hook's own `harnesses` line names. A hook you kept removed or declared off stays that way, and the skill warns that it is missing. The package page lists these hooks with the skill's other dependencies. The docs-writing skill uses it, so a repository that installs docs-writing gets the docs-writing-note hook on its next refresh.
