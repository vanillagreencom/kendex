- Bind agent model classes to native models on Codex and Copilot with `[model-bindings.<harness>]` in `kendex.toml`. This requires manifest format 7. Upgrade kendex to a release that reads format 7 before editing each personal and project manifest. Older readers refuse the newer format without changing the file; kendex does not convert formats. A schema 6 file reports: `kendex.toml: this manifest could not be read — it is a schema 6 manifest, and this kendex writes schema 7; move it aside and install fresh, declaring again from the file you moved`. After the upgrade, the one-line fix is `schema = 7`.
