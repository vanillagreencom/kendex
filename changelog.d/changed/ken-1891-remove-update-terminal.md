- `kendex remove`, `kendex update` and `kendex update-pi` now draw in a terminal like `refresh` and `apply`, with colour and a mark on each line for what it needs from you; a pipe, `NO_COLOR` and `TERM=dumb` still get plain lines. `kendex remove` asks about what nothing needs anymore with one key, `s` to remove it too or Enter to keep it, and the question counts and lists the changes a yes adds. With no terminal and neither `--sweep` nor `--no-sweep`, `kendex remove --scope all` now stops before any scope is written, where before it wrote the scopes ahead of the one that needed the answer. When `kendex update-pi` cannot save the install record for one place, it goes on to the other places, counts every package it installed in its closing line, still offers the commit, and then exits with the error. Before, it stopped at that place and did not say what it had installed.

  You do: in a script that runs `kendex remove` with no terminal, pass `--sweep` or `--no-sweep`.
