- `kendex project`, `kendex source`, `kendex marketplace` and `kendex check --catalog` now draw their lists, outcomes, warnings and checks in colour with status marks on a terminal, as the other converted commands do. A pipe, `NO_COLOR`, `TERM=dumb` and `--json` print the same text as before, apart from the two changes below. A source or subscription change, or an unsubscribe that keeps its packages, now says what it changed before it names a step after the change that failed. Before, that failure hid a change that was already written. When `kendex marketplace submit` refuses, it now says first that it did not submit because some checks did not pass, a check it could not read included, and then tells you to fix the checks marked above and submit again. Before, it named only the rows marked ✗ and offered `--dry-run` as a second step. On a terminal, a table no longer breaks a word or a name in the middle, and these lists keep each path whole; a row too wide for the terminal runs past its edge.
