- `kendex apply` and `kendex refresh` name `update-pi` for every declared Pi package whose installed copy or install record does not match its declaration, which their own write does not install and which Pi does not already load from the other scope: `settle-with=update-pi scope=project` (or `scope=global`) beside the packages and, where nothing else is left and `update-pi` can read every declared package, `finish-with=update-pi` with the same scope on the closing line, each with the project when `--project-path` named it. A package `refresh` leaves for `update-pi` because its install runs a process is named the same way, and the refresh still exits clean. Before, `apply` and such a `refresh` closed the scope as up to date. While such a package is left, the take-over is not named as the scope's finish, since it does not install it.
