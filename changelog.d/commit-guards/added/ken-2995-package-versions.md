- Catalog packages version on their own: `COMMIT_GUARDS_CHANGELOG_PACKAGE_PATHS` declares them, a `SKILL.md` versioning its directory and any other file, such as a hook script, naming a versionless package. A fragment under `changelog.d/<package>/<section>/` is that package's entry: it moves no program version, counts as no entry for a program change in `commit-msg`, must name a declared package, and collates under `### Packages`. Each change to a skill directory must raise its `metadata.version`, judged against the package fragments that change adds.
