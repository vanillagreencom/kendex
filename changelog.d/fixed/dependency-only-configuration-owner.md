- A review-file package that arrives only because another package requires it no longer takes the repository's review files over from an armed bot-instructions. bot-instructions keeps rendering and checking them, so `kendex verify` and the commit offer still catch drift, and `kendex apply` and `kendex refresh` name the pending setup. An add or apply without `--allow-repo-effects` that installs the new package beside a bot-instructions set up in that same checkout, while the new package is set up neither there nor in the main checkout, commits nothing and names that setup. Only that case is held. Set the new package up on its package page, or add the requiring package, or apply a hand-written declaration of it, with `--allow-repo-effects`, to move the files to it. That add or apply runs the setup once, before its commit offer, so its commit carries the new package's files, and the offer still sets up any other package it brings that holds the commit. Where it brings bot-instructions too, only the new package is set up, and a setup that fails is not run again at the commit offer.
