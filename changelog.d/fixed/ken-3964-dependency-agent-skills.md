- An agent a skill requires through `dependencies.agents` now installs with the skills its catalog assigns to it. A consumer `[agent-skills]` row for the agent replaces that assignment with the row's skills from the same catalog. An assignment never decides a skill's revision: an assigned skill that the scope declares, that a set brings or that any item requires keeps the revision those give it, whatever order the plan reads them in. An assigned skill is not installed when what it requires would take an item the scope holds to another revision, or when two agents' assignments want it at two revisions and no requirement decides; the agent warns that it lacks the skill.
