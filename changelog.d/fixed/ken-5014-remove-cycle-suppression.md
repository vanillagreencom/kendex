- `kendex remove` keeps an item removed only when something that stays requires it or a set that stays carries it. What stays is what you still declare, what a remaining set carries, and everything those require in turn. A hook or a cycle of skills that only the removed item brought in no longer holds it up, and neither does a requirer removed in the same command. Such a removal writes no `[suppressed]` line, so a skill or set added later that requires the item installs it again. While the catalog of something that requires the item cannot be read, kendex cannot tell whether that requirer stays, so it still keeps the item removed, as before, unless the same command removes the requirer too; the next `kendex add` of the item clears that line.
