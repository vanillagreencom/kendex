- `kendex remove` keeps an item removed only when something that stays requires it or a set that stays carries it. What stays is what you still declare, what a remaining set carries, and everything those require in turn. A hook or a cycle of skills that only the removed item brought in no longer holds it up, and neither does a requirer removed in the same command. Such a removal writes no `[suppressed]` line, so a skill or set added later that requires the item installs it again. While the item's catalog cannot be read, a hook that kendex leaves off every tool it targets, because a hook it requires is missing there, keeps the item removed only when you still declare that hook.
