- `kendex remove` keeps an item removed only when something that stays requires it or a set that stays carries it. What stays is what you still declare, what a remaining set carries, and everything those require in turn. A hook or a cycle of skills that only the removed item brought in no longer holds it up, and neither does a requirer removed in the same command. Such a removal writes no `[suppressed]` line, so a skill or set added later that requires the item installs it again. These fixes apply while every enabled catalog your `kendex.toml` lists can be read. While one cannot, `kendex remove` keeps the item removed as before: wherever something requires it that the same command does not remove. The next `kendex add` of the item clears that line.
