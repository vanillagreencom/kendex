- Relative links in skills from a path catalog reach the same file once installed, at the shared tree and at every tool's copy, and keep reaching it after the skill is kept on unsubscribe, adopted, forked or imported into a catalog. A skill saved in a template reads its links from the shared tree of whichever scope installs it. Links within a skill, to sibling skills or already reaching their target keep every byte. A link that cannot reach its target warns with `agent-link-unrepresentable` at install and `skill-link-kept` from the command that moved it, in the terminal and the desktop app, where an import lists them on its result and every other move shows one notification per link with its fix. In the desktop app, an unsubscribe whose call fails before it answers now closes and says the result is unknown, since it may already have landed, where it showed a refusal before.
