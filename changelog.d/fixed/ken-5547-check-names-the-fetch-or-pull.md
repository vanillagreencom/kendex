- `kendex check` now names the fix when a pulled install record names a catalog version this machine has not fetched: `kendex source refresh`, which fetches the catalog and writes nothing in the project. Before, the line only said that the next source refresh would try again. A checkout on its default branch that is behind origin's copy is told `git pull --ff-only` instead of `kendex refresh` for a package with a newer version, since the newer record is already on the default branch.
