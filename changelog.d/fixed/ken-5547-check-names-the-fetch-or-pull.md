- `kendex check` now names the fix when a pulled install record names a catalog version this machine has not fetched: `kendex source refresh`, which fetches the catalog and writes nothing in the project. Before, the line only said that the next source refresh would try again. A checkout on its default branch that is behind origin's copy is told `git pull --ff-only` instead of `kendex refresh` for a package with a newer version when origin's copy records that package at another version. After a pull changes the install record, the next check reads the package again instead of offering the refresh the old record called for. In `kendex check --json`, these fixes carry the remedy verbs `source-refresh` and `pull`.
