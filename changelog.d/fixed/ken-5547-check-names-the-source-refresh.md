- `kendex check` now names the fix when a pulled install record names a catalog version this machine has not fetched: `kendex source refresh`, which fetches the catalog and writes nothing in the project. Before, the line only said that the next source refresh would try again. After a pull changes the install record, the next check reads the package again instead of offering the refresh the old record called for, also where the pulled manifest has no enabled source left. In `kendex check --json`, this fix carries the remedy verb `source-refresh`.
