- A consumer refresh whose render removes or renames a heading that one of the repository's own files cites no longer lands or arms. The run checks the refreshed tree with the repository's installed md-refs, prints `refresh-md-refs=held` and `refresh-land=skipped value=md-refs`, and keeps the refresh pull request as a draft whose body names each broken citation with its file and line. A repository without md-refs prints `refresh-md-refs=skipped cause=absent`.
