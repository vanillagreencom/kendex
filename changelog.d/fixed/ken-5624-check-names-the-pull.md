- In a copy that follows its default branch and is behind origin's, `kendex check` now names `git pull --ff-only` instead of `kendex refresh` for a package that reads behind, where origin's copy records that package at another commit. The pull brings that record, and a refresh would write a record the copy must not commit. The check offers the pull only where it settles the line: the checkout is on the default branch, has no commits of its own, and its install record is the committed one. Otherwise it keeps naming the refresh. The check reads only what this clone last fetched. In `kendex check --json`, this fix carries the remedy verb `pull`.
