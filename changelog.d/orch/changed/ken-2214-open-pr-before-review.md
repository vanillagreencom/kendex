- On a repository GitHub reports private, a standard or small lane now pushes and opens its pull request right after the implement round's validated commit, and the one agent review runs on the open pull request beside Copilot's; its fix round and the fixes for Copilot's threads go out in one push, and the pull request is armed only once that review passed. A public or internal repository, or one whose visibility cannot be read, keeps review before push. The new `pr-order` script prints the order from `gh repo view --json visibility`, and the lane status file's `Review:` line names the pull request and head its review passed, which the overseer reads before it approves.
