- A lane or session launched from a running session no longer inherits that session's identity, so it can no longer write the parent's records or answer as the parent. The session id, nested-session markers, project directory and Jarvis runtime record are cleared in a tmux window, a detached terminal or wake, and on a hosted lane. A caller's own `--cmd` template that carries no account still runs as written, in the pane's shell.
