- The `CI_WAIT_NO_CHECKS_GRACE` default the orch settings template declares is now `600`, the grace `ci-wait` waits when the key is unset, instead of `180`, so saving the template's defaults no longer shortens the no-checks grace. `ci-wait` now waits the full grace in seconds rather than ending it up to one poll interval early, reads a leading-zero value such as `090` as 90 instead of aborting, and its help and the template state that an empty or non-numeric value waits the default.
