Keep an existing package in your own managed collection

Usage: kendex adopt [OPTIONS] <KIND> <NAME>

Arguments:
  <KIND>
          agent | skill | hook

  <NAME>
          

Options:
      --harness <HARNESS>
          The harness whose files to keep; repeat it to keep one package for
          several harnesses in a single pass, which is what a folder they share
          needs

  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global (default project)

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help
