Bookmark marketplace packages and bundles

Usage: kendex bookmark <COMMAND>

Commands:
  list     List bookmarks, and whether each one's marketplace still offers it
  show     Show a bookmark's source and whether it is still available
  add      Bookmark a marketplace package or bundle
  remove   Remove a bookmark. Packages installed from it stay installed
  install  Install a bookmarked package or bundle
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help
