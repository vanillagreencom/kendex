Check for package changes or problems on this computer

Usage: kendex check [OPTIONS]

Options:
  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global | all (default all)

      --json
          Machine-readable report

  -q, --quiet
          Print a short report, or nothing when all checks pass

  -v, --verbose
          Also show items a background refresh checks again, and the technical
          cause of each item

      --report-only
          Leave the project's install record as it is, and report what it lacks

      --catalog <CATALOG>
          Check this marketplace directory instead of this computer

      --strict
          With --catalog, also fail on advisories

  -h, --help
          Print help

path=PATH on stderr. A record with no version uses found=none.
