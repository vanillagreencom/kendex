Show changes between two versions of a package

Usage: kendex diff [OPTIONS] --from <FROM> <KIND> <NAME>

Arguments:
  <KIND>
          agent | skill | hook | command | mcp-server | pi-extension

  <NAME>
          

Options:
      --from <FROM>
          A version (tag, branch, commit) or `installed`

      --to <TO>
          A version (tag, branch, commit) or `installed` (the default)
          
          [default: installed]

      --harness <HARNESS>
          Which harness's installed files to compare (default claude)

  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global (default project)

  -h, --help
          Print help
