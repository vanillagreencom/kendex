Keep an edited package as your own copy

Usage: kendex fork [OPTIONS] <KIND> <NAME>

Arguments:
  <KIND>
          agent | skill

  <NAME>
          

Options:
      --rename <RENAME>
          Rename your own copy to this name instead of making one

      --harness <HARNESS>
          Which harness's installed files hold the edit (agents; default claude)

  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global (default project)

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help
