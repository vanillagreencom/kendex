Set up and run checks before each Git commit

Usage: kendex guard <COMMAND>

Commands:
  run        Run the checks for a Git hook
  install    Turn on this repository's Git commit checks
  uninstall  Turn off this repository's Git commit checks
  check      Check whether this repository's Git hooks are active
  help       Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help
