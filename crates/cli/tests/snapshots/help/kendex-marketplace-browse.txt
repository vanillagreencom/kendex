List packages and bundles from your subscribed marketplaces

Usage: kendex marketplace browse [OPTIONS] [MARKETPLACE]

Arguments:
  [MARKETPLACE]
          The subscription to browse (default: every subscription in scope)

Options:
  -h, --help
          Print help

Output:
      --json
          Print the list as JSON

Where:
  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global | all (default all)
