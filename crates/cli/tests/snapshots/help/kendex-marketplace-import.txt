Copy packages from this computer into an authored marketplace. With no
selections, lists every candidate and where its bytes live

Usage: kendex marketplace import [OPTIONS] <TARGET>

Arguments:
  <TARGET>
          The authored marketplace directory to copy into

Options:
      --skill <SKILLS>
          

      --agent <AGENTS>
          

      --hook <HOOKS>
          

      --command <COMMANDS>
          

      --mcp <MCP>
          

      --from-scope <FROM_SCOPE>
          project | global | all (default all) — where candidates come from

      --origin <ORIGIN>
          When one name exists with different bytes in several places: the hash
          (prefix) of the origin to copy

      --as <RENAME>
          Destination name when the original would be refused (one selection
          only)

      --confirm-license
          Confirm the shown license of a package from a marketplace allows
          republishing

      --license-basis <LICENSE_BASIS>
          A package from a marketplace with no license found: your reason for
          copying

      --json
          Print the packages available to copy as JSON

  -h, --help
          Print help
