Subscribe to a marketplace: `owner/repo[@rev]`, a git URL, a GitHub tree URL, a
skills.sh package URL, or a local folder

Usage: kendex marketplace subscribe [OPTIONS] <REFERENCE>

Arguments:
  <REFERENCE>
          

Options:
      --name <NAME>
          Name for the subscription (default: the last path segment)

  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global (default project)

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help
