Unsubscribe from a marketplace, removing or keeping its packages

Usage: kendex marketplace unsubscribe [OPTIONS] <NAME>

Arguments:
  <NAME>
          

Options:
      --remove-packages
          Remove everything installed from it

      --keep-packages
          Keep its packages as your own copies

      --discard-edits
          With --remove-packages: discard edits on disk too, instead of refusing

  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global (default project)

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help
