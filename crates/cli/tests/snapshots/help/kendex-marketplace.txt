Subscribe to marketplaces and list subscriptions

Usage: kendex marketplace <COMMAND>

Commands:
  list         List marketplace subscriptions and package counts
  subscribe    Subscribe to a marketplace: `owner/repo[@rev]`, a git URL, a
               GitHub tree URL, a skills.sh package URL, or a local folder
  unsubscribe  Unsubscribe from a marketplace, removing or keeping its packages
  browse       List packages and bundles from your subscribed marketplaces
  check        Check a marketplace folder for problems
  new          Create a marketplace folder with package checks
  use          Add an existing marketplace folder to Mine without changing its
               files
  mine         List your own marketplaces and show whether they are ready to
               share
  import       Copy packages from this computer into an authored marketplace.
               With no selections, lists every candidate and where its bytes
               live
  submit       Submit your marketplace to the kendex.ai community directory
  help         Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help
