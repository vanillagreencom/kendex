Hold a package at a version, or let it follow its marketplace again

Usage: kendex pin [OPTIONS] <KIND> <NAME> [VERSION]

Arguments:
  <KIND>
          agent | skill | hook | command | mcp-server | pi-extension

  <NAME>
          

  [VERSION]
          The version to hold at: a tag, branch, or commit

Options:
      --follow
          Follow the marketplace's own version again

  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global (default project)

  -y, --yes
          Skip confirmation prompts

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help
