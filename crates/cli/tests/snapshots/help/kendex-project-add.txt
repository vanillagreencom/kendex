Add a project folder to Projects

Usage: kendex project add [OPTIONS] <PATH>

Arguments:
  <PATH>
          

Options:
      --drift-hook
          Also install package checks there, which run when a session starts

      --template <TEMPLATE>
          Install this saved template into the project once it is registered

  -y, --yes
          Skip confirmation prompts (with --drift-hook or --template)

      --throwaway
          Add a throwaway project to Projects: a folder under a temporary path,
          which is otherwise refused

  -h, --help
          Print help
