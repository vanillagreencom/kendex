Update installed packages from your saved setup

Usage: kendex refresh [OPTIONS]

Options:
  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global | all (default all)

  -v, --verbose
          Per-item detail instead of the compact summary

  -y, --yes
          Accept changes to what is installed without asking

      --discard-edits
          Overwrite installations you edited by hand

      --project-path <PATH>
          The project this run reads and writes, by path, instead of the one it
          was typed in

      --lane-refresh
          Permit project writes in a marked lane whose item is a refresh

      --throwaway
          Add a throwaway project to Projects: a folder under a temporary path,
          which is otherwise refused

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help
