Remove installed packages

Usage: kendex remove [OPTIONS] [NAMES]...

Arguments:
  [NAMES]...
          

Options:
      --kind <KIND>
          Narrow to agent | skill | hook | command | mcp-server | plugin |
          pi-extension

  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global | all (default project)

      --sweep
          Also remove what nothing needs anymore

      --no-sweep
          Keep what nothing needs anymore

      --keep-declaration
          Take the files away and leave kendex.toml untouched; refresh installs
          what it lists again

      --allow-repo-effects
          With --commit, --push or --pull-request, say yes to setting up a
          package that holds the commit

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help
