Report a problem to the repository that maintains a package

Usage: kendex report [OPTIONS] --title <TITLE>

Options:
      --title <TITLE>
          Issue title

      --body <BODY>
          Issue body text

      --body-file <BODY_FILE>
          Read the body from a file

      --upstream <UPSTREAM>
          Repository for reports about kendex packages

      --area <AREA>
          Routing label: cli | skills | harness | review-gate | docs | tech-debt

      --dry-run
          Preview the destination and submission arguments without filing an
          issue

  -h, --help
          Print help

Packages:
      --skill <SKILL>
          Report about an installed skill

      --agent <AGENT>
          Report about an installed agent

      --hook <HOOK>
          Report about an installed hook

      --asset <ASSET>
          Report about any installed package by name

Where:
  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          Where to read the package: project or global (default project)
