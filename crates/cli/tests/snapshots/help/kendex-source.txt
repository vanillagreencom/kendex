Add, switch on or off, and check marketplaces for updates

Usage: kendex source [OPTIONS] <COMMAND>

Commands:
  list     List the marketplaces this place installs from, and which are
           switched off
  add      Add a marketplace: `owner/repo[@rev]`, a git URL, or a local path
  remove   Remove a marketplace (refused while packages still come from it)
  enable   Switch a marketplace back on here and restore the packages installed
           from it
  disable  Switch a marketplace off here: the packages installed from it switch
           off, nothing is deleted, and switching it back on puts them back
  refresh  Check marketplaces for updates
  help     Print this message or the help of the given subcommand(s)

Options:
  -g, --global
          Use your personal setup instead of this project

      --scope <SCOPE>
          project | global | all (default project; all for refresh --stale)

  -h, --help
          Print help
