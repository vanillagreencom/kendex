Save a template — from a project with --from-project, or from packages a
marketplace offers

Usage: kendex template create [OPTIONS] <NAME>

Arguments:
  <NAME>
          

Options:
      --from-project <FROM_PROJECT>
          Take every package this project manages

      --include-local
          Also copy the project's packages that kendex does not manage

      --include-customizations
          Also save what this project customized for the included packages

      --exclude <EXCLUDED>
          Leave a package out, as `<kind>:<name>`; repeat for more

      --use-marketplace <USE_MARKETPLACE>
          For a package this project edited, save the marketplace's version —
          `<kind>:<name>`; repeat for more

      --use-project-copy <USE_PROJECT_COPY>
          For a package this project edited, save this project's own copy —
          `<kind>:<name>`; repeat for more

      --confirm-license
          Confirm the marketplace's license allows copying, for every
          --use-project-copy whose license kendex recognizes

      --license-basis <LICENSE_BASIS>
          Your reason for copying, for a --use-project-copy whose license kendex
          does not recognize

      --source <SOURCE>
          The marketplace these packages come from — `owner/repo` or a folder.
          Naming it also tells two members of one kind and name apart; without
          it a removal reaches every member wearing them

  -a, --agent <AGENT>
          

  -s, --skill <SKILL>
          

      --hook <HOOK>
          

      --command <COMMAND>
          

      --mcp-server <MCP_SERVER>
          

  -b, --bundle <BUNDLE>
          Bundles the marketplace offers, each installed whole

      --plugin <PLUGIN>
          Plugins, each installed whole like a bundle

  -y, --yes
          Skip confirmation prompts

  -h, --help
          Print help
