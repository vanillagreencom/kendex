Install a template into a project, or into the personal setup

Usage: kendex template install [OPTIONS] <NAME>

Arguments:
  <NAME>
          

Options:
      --project <PROJECT>
          The project to install into; without it the personal setup

  -y, --yes
          

      --throwaway
          Add a throwaway project to Projects: a folder under a temporary path,
          which is otherwise refused

  -h, --help
          Print help
