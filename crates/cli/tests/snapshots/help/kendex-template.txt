Save a group of packages and install it into any project

Usage: kendex template <COMMAND>

Commands:
  list     List saved templates
  show     Show a template's packages and any missing sources
  create   Save a template — from a project with --from-project, or from
           packages a marketplace offers
  add      Add packages to a template
  remove   Take packages out of a template
  rename   Give a template another name
  install  Install a template into a project, or into the personal setup
  delete   Delete a template. Packages installed from it stay installed
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help
          Print help
