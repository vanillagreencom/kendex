Find the AI model for a harness and performance tier

Usage: kendex tier-model [OPTIONS] <HARNESS> [RANK]

Arguments:
  <HARNESS>
          Native receiving harness

  [RANK]
          Legacy class rank, top first; selector-only output is not access
          evidence

Options:
      --model <MODEL>
          Model class, native family, exact pin or inherit

      --agent <AGENT>
          Native declared Claude agent identity at the child working directory

      --runtime-context-stdin
          Read model-resolution-v1 runtime context from stdin

      --runtime-context-json <RUNTIME_CONTEXT_JSON>
          Argument-array alternative for native process APIs

      --discover-codex-models
          Replace supplied list evidence with local Codex model/list under this
          account

      --json
          Tagged model-resolution-v1 response; the caller prints its warning
          once

  -h, --help
          Print help
