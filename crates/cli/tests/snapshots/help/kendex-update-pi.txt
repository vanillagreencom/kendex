Update Pi extension packages

Pi loads user and project package lists together. Installing the same package in
both prevents Pi from starting. Keep either copy and remove the other before
updating.

Usage: kendex update-pi [OPTIONS]

Options:
  -c, --check
          Print the plan and change nothing

      --scope <SCOPE>
          project | global | all (default all)

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help (see a summary with '-h')
