Install and manage packages for your AI coding harnesses.

Usage: kendex [OPTIONS] [SOURCE] [COMMAND]

Commands:
  add              Install agents, skills, and more from a marketplace or
                   repository
  diff             Show changes between two versions of a package
  show             Show a package's files, readme, or source
  fork             Keep an edited package as your own copy
  pin              Hold a package at a version, or let it follow its marketplace
                   again
  versions         List available versions of a package
  updates          Find package updates and manage update notifications
  enable           Switch installed packages on
  disable          Switch installed packages off
  remove           Remove installed packages
  refresh          Update installed packages from your saved setup
  verify           Check that installed files match your saved setup
  apply            Make installed packages match your saved setup
  adopt            Keep an existing package in your own managed collection
  project          Add, list, and find projects
  template         Save a group of packages and install it into any project
  bookmark         Bookmark marketplace packages and bundles
  list             List every package found on this computer
  check            Check for package changes or problems on this computer
  drift-hook       Set up package checks at the start of each coding session
  guard            Set up and run checks before each Git commit
  source           Add, switch on or off, and check marketplaces for updates
  marketplace      Subscribe to marketplaces and list subscriptions
  trash            List removed files or empty the trash
  login            Sign in to kendex.ai with a code in your browser
  logout           Sign out of kendex.ai on this computer
  index            Summarize the packages in a marketplace folder
  init             Start a marketplace package in the current directory
  update           Install a newer version of kendex
  version-compare  Compare two version numbers
  harness-paths    List the project paths each harness reads, as JSON
  hooks-off        Name the Copilot file that turns all hooks off, as JSON
  tier-model       Find the AI model for a harness and performance tier
  update-pi        Update Pi extension packages
  help             Print this message or the help of the given subcommand(s)

Arguments:
  [SOURCE]
          Marketplace or repository to install from

Options:
  -g, --global
          Install to the user-level scope

      --harness <HARNESS>
          Target harnesses (comma-separated)

      --all-harnesses
          Target every harness kendex can install to at this scope

  -a, --agent <AGENT>
          Install specific agents (comma-separated)

  -s, --skill <SKILL>
          Install specific skills (comma-separated)

  -b, --bundle <BUNDLE>
          Install whole bundles the marketplace offers (comma-separated)

      --with <OPTIONAL>
          Also take these optional dependencies (comma-separated)

      --hook <HOOK>
          Install specific hooks (comma-separated)

      --output-style <OUTPUT_STYLE>
          Install one response style

      --command <COMMAND>
          Install specific commands (comma-separated)

      --mcp-server <MCP_SERVER>
          Install specific MCP servers (comma-separated)

      --pi-extension <PI_EXTENSION>
          Install specific Pi extensions (comma-separated)
          
          [alias: --pi-package]

      --copy
          Copy instead of symlink

      --method <METHOD>
          Delivery: symlink (one shared tree) or copy (a tree per harness)
          
          [possible values: symlink, copy]

  -y, --yes
          Skip confirmation prompts

      --all
          Every package the marketplace offers

      --clobber
          Allow --global --all when your personal setup already has an install
          record

      --no-auto-skills
          Skip auto-install of skills referenced by selected agents

      --hold
          Hold what this installs at the resolved version (manual updates)

      --allow-repo-effects
          Say yes to the repository changes a package declares

      --setting <KEY=VALUE>
          Write a project setting a package here declares, as KEY=VALUE; a key
          kendex.settings.toml already assigns keeps its value

      --throwaway
          Add a throwaway project to Projects: a folder under a temporary path,
          which is otherwise refused

      --commit
          Commit the files kendex wrote, without asking

      --push
          Commit them and push, without asking

      --pull-request
          Commit them on a new branch and open a pull request, without asking

      --leave
          Leave them as diffs, without asking

      --message <MESSAGE>
          The commit message to use instead of the default

  -h, --help
          Print help

  -V, --version
          Print version
