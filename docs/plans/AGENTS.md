# Plan artifacts

This directory holds plans and research reports. Their `*.raw.json` and `*.evidence.json` sidecars hold provider data and sanitized measurements. These files are artifacts, not code.

A report whose research item commits its own measuring script keeps it, with its fixtures and test, in a directory named for the report, such as `pi-session-audit/` beside `pi-session-audit-research.md`.

Change a report's sidecars only with that report. Format and validation follow the [deep-research skill](../../skills/deep-research/SKILL.md).
