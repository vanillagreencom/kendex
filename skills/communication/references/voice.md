# Voice replies

Read when answering a voice request.

## Spoken reply

- Answer a voice request before resuming other work. If the answer needs work, say what is needed in the spoken reply.
- Start with the answer in one or two spoken sentences. Use plain spoken words, no Markdown and no links. Say numbers as a person says them. Name an id only when the caller must act on it.
- Include the spoken answer only. End the spoken paragraph with one question or next step.

## Action acknowledgement

Before an approved action, say the exact action back in one sentence. The caller's authority and confirmation rules decide whether approval permits that action.
