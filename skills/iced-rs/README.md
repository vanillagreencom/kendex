# Iced 0.14

Reference material for agents building Iced desktop interfaces in Rust. It includes framework examples and guides for widgets, drawing and application state.

## Install

```bash
kendex add vanillagreencom/kendex --skill iced-rs
```

## Features

- Find an example for the interface element being built.
- Read guides for custom widgets, overlays and animation.
- Look up widget usage and framework constraints.

## How it works

The agent loads [SKILL.md](SKILL.md) when it works on an Iced interface. It selects the type of interface element and opens the matching example. It then loads the relevant guide from [references/INDEX.md](references/INDEX.md).

## Settings

Nothing to configure.
