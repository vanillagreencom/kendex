# Clock

Draw a clock face and hands on Canvas and update them on timer ticks.

![Canvas clock face and hands](https://user-images.githubusercontent.com/518289/74716344-a3e6b300-522e-11ea-8aea-3cc0a5100a2e.gif)

Read the [example source](src/main.rs).

## Run

Run from the root of the [Iced 0.14.0 workspace](../README.md#install).

```sh
cargo run --package clock
```
