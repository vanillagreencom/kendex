# Game of Life

Pan, zoom, and edit the grid without fixed edges while the simulation advances in the background.

![A Game of Life grid](https://iced.rs/examples/game_of_life.gif)

This example implements [Conway’s Game of Life](https://en.wikipedia.org/wiki/Conway%27s_Game_of_Life), devised by [John Horton Conway](https://en.wikipedia.org/wiki/John_Horton_Conway).

Read the [example source](src/main.rs).

## Run

Run from the root of the [Iced 0.14.0 workspace](../README.md#install).

```sh
cargo run --package game_of_life
```
