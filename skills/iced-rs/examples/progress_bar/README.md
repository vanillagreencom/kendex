# Progress bar

Use a slider to change the progress bar’s value. Switch between horizontal and vertical layouts.

![A progress bar controlled by a slider](https://iced.rs/examples/progress_bar.gif)

Read the [example source](src/main.rs).

## Run

Run from the root of the [Iced 0.14.0 workspace](../README.md#install).

```sh
cargo run --package progress_bar
```
