# Tour

Try Iced widgets in a single app that runs on desktop and in a browser.

[![A tour of Iced widgets](https://iced.rs/examples/tour.gif)](https://iced.rs/examples/tour.mp4)

Read the state, messages, update, and view definitions together in the example source.

Read the [example source](src/main.rs).

## Run

Run from the root of the [Iced 0.14.0 workspace](../README.md#install).

```sh
cargo run --package tour
```

## Web

With [Trunk](https://trunk-rs.github.io/trunk/guide/) installed, run from the upstream workspace root.

```sh
cd examples/tour
trunk serve
```
