# Communication

Read [communication](../../communication/SKILL.md) before a message to the user.

## Message types

| Type | Wording or local requirement | Send when |
|---|---|---|
| Decision request | [Questions](../../communication/references/questions.md) | A decision blocks an action under [decisions.md](decisions.md#authority) |
| Critical notice | [Message purpose](../../communication/references/messages.md#message-purpose) | Work stops, data or money is at risk, or timely user action is required |
| Input-device notice | Name the mouse or keyboard action and when, under [action requests](../../communication/references/questions.md#action-requests) | Before taking control; wait for the user's agreement |
| Progress report | [Reports](../../communication/references/reports.md) | At the cadence the user sets. Before a session handoff only when the user set no rule for it |
| Reply | [Messages](../../communication/references/messages.md) | The user asks or gives information that needs an answer |

Send messages only for these types.

## Delivery

- Apply [verification.md](verification.md#sources) to each claim before sending the message.
- Complete new accounts under [Owner setup](../../orch/references/communication-modes.md#owner-setup).
